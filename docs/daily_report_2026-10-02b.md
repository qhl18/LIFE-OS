### 2. 表格导入：Excel / CSV / 粘贴 → 课表
- 位置：今日板块 → 日程管理 → 「从表格导入」
- 三种入口：选 Excel 文件、选 CSV、或从 Excel 里复制一块直接粘贴
- 全程：解析 → 列自动映射（不对就手改下拉框）→ 预览表 → **逐行勾选** → 写入
- 铁律落地：缺星期或名称的行自动禁用；解析失败不落库；Excel 引擎（SheetJS）内置本地，不联网
- 多星期自动展开：填「一,三,五」一条 = 三条每周日程

### 3. OCR 半自动：睡眠截图 → 草稿
- 位置：手环粘贴弹窗 → 「从截图识别（半自动）」

- 第一次用要加载引擎约 20 秒，之后秒开
